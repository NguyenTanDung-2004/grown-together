# How to use this project?
1. Clone, fetch and switch to this branch
```
git clone https://github.com/NguyenTanDung-2004/grown-together.git
git fetch
git checkout -b outbox-pattern --track origin/outbox-pattern
```

2. Run docker-compose to start mysql. (you need to setup docker before)
```
docker-compose run up -d
```

3. Run project. 
```
mvn spring-boot:run
```
`Note: If you have any problem, feel free to contact me.`
